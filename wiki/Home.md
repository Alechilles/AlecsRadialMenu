# Alec's Radial Menu Wiki

Alec's Radial Menu is an asset-driven radial menu framework for Hytale servers. A menu can run commands, start native interactions, call registered Java actions, or change the NPC that opened it.

## Browse the wiki

- [Start Here](/mod/alecs-radial-menu/start-here) — Install the mod and create your first menu.
- [Menu Authoring](/mod/alecs-radial-menu/menu-authoring) — Configure menu options, execution modes, feedback, and visuals.
- [NPC Integration](/mod/alecs-radial-menu/npc-integration) — Open a menu from an NPC and send the result back to its role.
- [Developer Integration](/mod/alecs-radial-menu/developer-integration) — Open menus and register actions through the Java API.
- [Reference Library](/mod/alecs-radial-menu/reference-library) — Check compatibility, limits, and common fixes.

- [Create a first radial menu](/mod/alecs-radial-menu/first-radial-menu)

- [Set an NPC state or role flag](/mod/alecs-radial-menu/states-results-and-npc-actions)
- [Test the included example NPC](/mod/alecs-radial-menu/example-npc-workflow)

Menu assets belong in `Server/RadialMenu/Menus`. The file name and path form the menu key. A menu asset does not contain a separate `Id` field.
