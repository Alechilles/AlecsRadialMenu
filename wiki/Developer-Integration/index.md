# Developer Integration

Parent: [Alec's Radial Menu](/mod/alecs-radial-menu/home)

The Java API lets another mod open menus, execute armed selections, inspect registered IDs, and provide custom action handlers.

- [Java API and Registered Actions](/mod/alecs-radial-menu/java-api-and-registered-actions)

Use `InvokeRegisteredAction` for player-only code. Use `InvokeRegisteredNpcAction` when the callback needs the NPC that opened the menu.
