# NPC Integration

Parent: [Alec's Radial Menu](/mod/alecs-radial-menu/home)

An NPC role can open a target-aware radial menu when a player interacts with it. The selected option can change the NPC state, emit a result into the role, or call another mod with the live target.

- [NPC Interaction Setup](/mod/alecs-radial-menu/npc-interaction-setup)
- [States, Results, and NPC Actions](/mod/alecs-radial-menu/states-results-and-npc-actions)
- [Example NPC Workflow](/mod/alecs-radial-menu/example-npc-workflow)

Use a named result when the role must run a native NPC action such as `SetFlag`, `State`, `PlayAnimation`, or a sequence of actions.
